## Portfolio at a Glance

The knowledge base tracks a core set of portfolio-level data points that give the investment team an accurate, real-time picture of how the overall portfolio is performing. Keep each of these metrics current so that quarterly reporting and LP updates reflect the most accurate state of the fund.

| Metric | Description |
|---|---|
| Active Portfolio Companies | The total number of companies in which Capria currently holds an equity position |
| Total Invested Capital | The cumulative amount of capital deployed across all portfolio companies and all rounds |
| Realized vs. Unrealized Value | Realized value represents proceeds from exits; unrealized value reflects the current marked carrying value of active holdings |
| Average Ownership Stake | The average fully diluted ownership percentage Capria holds across all active portfolio companies |
| Number of Exits | The count of full and partial exits, including IPOs, M&A transactions, and secondary sales |

<Note>
  Portfolio data should be reviewed and updated quarterly, or immediately after each significant company milestone — including new funding rounds, executive changes, material revenue events, or any liquidity transaction.
</Note>
