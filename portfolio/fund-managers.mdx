## What sits on each manager page

Each fund manager page carries the same structure as a company page: the three links out (Drive, Dropbox, Attio), a position summary including total committed capital, a row per fund vehicle holding the relationship, and the firm profile pulled from Attio — sector focus, headquarters, founding year, team size and the primary GP contact.

## Folder conventions

| System | Path |
| --- | --- |
| Dropbox | `Investments / <Region> / Portfolio - FM / <Manager>` |
| Dropbox (shared data room) | `... / <Manager> / <Manager> - Capria Data Room SHARED` |
| Dropbox (warehouse) | `... / <Manager> / Warehouse / Warehouse - <Company>` |
| Google Drive | `<Region> Portfolio - FM / <Manager>` |

<Note>
  Offboarded managers keep their files under `Investments / z - Archive / z - Capria Portfolio - FM (moved to regional folders) / y - Offboarded FMs`. Adobe Capital's relationship is now managed under Deetken Impact, and both pages point at the same Attio record.
</Note>
