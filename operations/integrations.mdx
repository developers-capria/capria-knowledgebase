The knowledge base is more valuable when it connects to the tools the team already uses. Rather than maintaining data in silos, Capria's approach is to establish clear data flows from each external system into the knowledge base — so that fund administration data, CRM records, market data, and legal documents all converge in one place. This page covers how data moves from fund administration platforms, financial systems, and portfolio data providers into the knowledge base, and how to keep those flows accurate and timely.

## Fund Administration Integration

The fund administrator (FA) is the authoritative source for all LP-level financial data. Treat FA-generated records as the source of truth for the following data categories:

- **LP capital account balances** — Each LP's current NAV, including unrealized value and cumulative distributions received
- **Called and uncalled capital per LP** — Running totals of capital drawn and remaining commitment for every LP in the fund
- **Audited financial statements** — Annual audited financials prepared in accordance with GAAP or IFRS, as applicable
- **Distribution records** — Wire confirmations and distribution ledgers for every distribution event

Sync FA data into the knowledge base using the following process:

- **Quarterly reconciliation** — After each quarter-end, import the FA-generated capital account statements and reconcile them line by line against knowledge base records. Resolve all discrepancies before LP reporting is finalized.
- **Distribution events** — After each distribution is wired, import the FA's wire confirmation data and update each LP's distribution history and running DPI in the knowledge base.
- **Annual audit** — Use FA statements as the source of record for all audited financial figures. Knowledge base entries for fund financials should match the audited statements exactly; any prior estimates should be updated to reflect audited actuals.

<Note>
  The fund administrator's numbers are the authoritative source for all LP-level financial data. If you identify a discrepancy between knowledge base records and FA statements, resolve it directly with the FA before issuing any LP report or capital account statement. Never distribute LP-facing financial data that has not been reconciled against FA records.
</Note>

## CRM and Deal Tracking

Your CRM is the system of record for relationship data — deal pipelines, LP contacts, and portfolio company contacts. Keeping it synchronized with the knowledge base ensures that investment records and relationship history stay connected.

Use your CRM to manage:

- **Deal pipeline** — Prospect companies, deals in due diligence, and closed investments. The CRM tracks the full deal lifecycle from sourcing through close.
- **LP relationship management** — LP contact details, meeting notes, communication history, and commitment status across all funds.
- **Portfolio company contacts** — Key founder and operator contacts at each portfolio company.

Common tools in use at VC firms include **Affinity**, **Salesforce**, **DealCloud**, and **Attio**. Regardless of which platform Capria uses, apply the following sync practices to keep the knowledge base aligned:

- **New deal closed** → Immediately create the investment record and company profile in the knowledge base. The CRM records the relationship; the knowledge base records the financial details.
- **LP contact updated in CRM** → Reflect the change in the LP's knowledge base record, including updated wire instructions, addresses, or key contact personnel. Outdated LP contacts create distribution and communication failures.
- **Quarterly meeting notes** → Log key discussion points from LP meetings in the LP's knowledge base record. Summaries of questions asked, concerns raised, and commitments made are valuable context for future interactions.

## Financial Data Providers

Market data and valuation benchmarks flow from external data providers into the performance reporting section of the knowledge base. Use the following sources for their respective data types:

- **PitchBook / Crunchbase** — Use for comparable transaction data, market valuations, and verification of portfolio company funding history. When assessing a valuation mark, pull relevant comparable rounds from PitchBook and document them in the valuation notes.
- **Preqin / Cambridge Associates** — Use for benchmark data on fund performance by vintage year, strategy, and geography. Import benchmark datasets quarterly to populate the fund performance comparison section of LP reports.
- **Bloomberg / FactSet** — Use for public market data required in Public Market Equivalent (PME) calculations. Pull index return data at quarter-end to run PME benchmarking alongside IRR.

Download benchmark datasets at each quarter-end and import them into the performance reporting section of the knowledge base. Label each dataset with its source, the download date, and the period it covers so that future readers can trace the data's origin.

## Document Management

Legal and fund documents require a consistent storage and referencing structure. Follow these conventions to ensure every document is easy to locate and correctly versioned.

- **Executed fund documents** (LPA, subscription agreements, side letters) → Store in the document archive with explicit version numbers. When an amendment is executed, retain the prior version as superseded and add the new version with its execution date.
- **Portfolio company documents** (term sheets, stock purchase agreements, cap tables, board consents) → Store per company within that company's portfolio record. Organize by round so that the complete document set for each financing is grouped together.
- **LP reports and capital call notices** → Archive by fund and date. Every LP communication should be retained in the knowledge base so that the full history of LP-facing disclosures is accessible.

Use the following folder naming convention for all stored documents:

```text
/Funds/[Fund Name]/[Document Type]/[YYYY-MM-DD] [Document Name]
/Portfolio/[Company Name]/[Round]/[Document Type]
```

For example:
```text
/Funds/Capria Fund III/LPA/2021-06-15 Capria Fund III Limited Partnership Agreement v1.0
/Portfolio/Acme Technologies/Series A/Stock Purchase Agreement
```

<Tip>
  Establish a single source of truth for each data type and document which system holds the authoritative record. When every team member knows where to find the authoritative version of any given data point, you eliminate the confusion and errors that arise from competing records.
</Tip>
